# Vector Database

Dit is een educatief C++-project waarin ik vanaf de basis een eigen Vector Database bouw.

Het doel is niet alleen een werkend programma maken, maar leren hoe een dergelijk systeem technisch werkt.

## Eerst

We beginnen zonder Machine Learning.

De eerste versie moet onder andere kunnen:

* vectors opslaan
* vectors toevoegen en verwijderen
* vectors vergelijken
* similarity/afstand berekenen
* nearest neighbors zoeken
* top-k resultaten teruggeven

De eerste zoekmethode wordt bewust simpel: brute force.

Daarna onderzoeken we hoe we dit sneller en efficiënter kunnen maken met verschillende datastructuren en algoritmes.
